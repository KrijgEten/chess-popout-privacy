Chess Popout Privacy Policy

Last updated: October 21, 2026. Applies to Chess Popout version 0.1.2.

Chess Popout, published by Leander Scholman, opens your existing Chess.com game interface in an interactive floating window. The extension has no developer-operated data collection server, advertising system, or analytics service.

Website content processed locally

The extension accesses and temporarily uses the existing Chess.com board, piece positions, clocks, player information, game controls, game results, and related interface elements to display the original game in the floating window. When full controls are enabled, the original sidebar content can also appear there. This processing takes place in your browser. Player information or chat that is already part of the original Chess.com interface is not extracted into separate profiles or datasets by the extension.

To provide an optional move alert, the extension compares visible piece positions and, where available, the active clock. This temporary state is released when the floating window closes.

Input handling

Mouse, pointer, touch, and keyboard events are passed to the original Chess.com interface so its controls remain usable. The extension does not record keystrokes, create clickstream logs, or build usage profiles. It does not access unrelated websites or monitor other applications.

Preferences stored on your device

Chrome local extension storage saves only the floating-window dimensions, the move-alert preference, and the full-controls preference. These settings are not synced by the extension. Game history, Chess.com credentials, player profiles, and chat records are not saved to extension storage.

Network requests and third parties

The extension does not send game content, player information, input events, or preferences to the developer, advertisers, or analytics providers. It does not sell user data or use it for advertising, credit decisions, or purposes unrelated to the floating game interface.

Chess.com continues to operate the original game and handle its normal service connections. To preserve the original appearance, the browser may reload stylesheets, fonts, or images already referenced by the Chess.com page. Those requests go to the original website resource providers and can include normal request information, such as an IP address. Chess.com and its resource providers handle their services under their own privacy policies.

Retention and your choices

Temporary interface and board state is used only while needed for the floating window. Local preferences remain until they are changed, cleared through Chrome, or removed by uninstalling the extension. You can disable the move alert or full controls, return the board to its tab, or uninstall the extension at any time. Uninstalling the extension does not delete information held independently by Chess.com.

Limited use

Information accessed by Chess Popout is used only to provide its disclosed floating-board functionality and related display preferences. The extension's use of this information follows the Chrome Web Store User Data Policy, including its Limited Use requirements. The developer does not receive or read users' game content through the extension.
